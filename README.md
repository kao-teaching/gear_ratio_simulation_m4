# Gear Ratio Simulator

เว็บไซต์ต้นแบบสำหรับการเรียนรู้เรื่องอัตราทดเฟืองและการเลือกเกียร์ให้เหมาะกับสนามทางเรียบ/ทางลาดชัน

## ไฟล์
- `index.html` — เว็บไซต์ทั้งหมด (HTML, CSS, JavaScript อยู่ในไฟล์เดียว)

## ทดลองบนเครื่อง
เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งโปรแกรมเพิ่ม

## Deploy ผ่าน GitHub Pages
1. สร้าง GitHub repository ใหม่ เช่น `gear-ratio-simulator`
2. อัปโหลด `index.html` ไปไว้ที่ root ของ repository
3. เข้าเมนู **Settings → Pages**
4. ในหัวข้อ **Build and deployment** เลือก `Deploy from a branch`
5. เลือก branch `main` และ folder `/ (root)` แล้วกด **Save**
6. รอสักครู่ GitHub จะแสดง URL เว็บไซต์ในหน้า Pages

## หมายเหตุด้านแบบจำลอง
- Wheel RPM และแรงบิดที่ล้อคำนวณจากอัตราทดเฟืองแบบอุดมคติ
- การจำลองการเคลื่อนที่ใช้แบบจำลองแรงฉุดอย่างง่ายเพื่อประกอบการเรียนรู้ ไม่ใช่เครื่องมือออกแบบยานยนต์หรือค่าทดสอบจริง
- ค่าจริงขึ้นอยู่กับกราฟแรงบิด-ความเร็วรอบของมอเตอร์ ประสิทธิภาพชุดเฟือง รัศมีล้อ มวลรถ แรงเสียดทาน และแรงยึดเกาะ
- หากนำไปใช้ทดลองจริง ควรใช้ผลการวัดจากรถต้นแบบมาเปรียบเทียบกับค่าจำลอง
